# v1 prototype — 2026-09-23

Snapshot of the printable files at git tag `v1-prototype` (commit b3ad828).
Printed in PLA on the Snapmaker U1: tray, two dividers, base (supports on the
cord port ceiling only, brim), lid. Charger: Anker A2154 (nominal dimensions;
port pitch, inlet height and cord end still unmeasured at this point).

Regenerate from source with `uv run python scripts/export_all.py`; these
copies are kept so the prototype can be reprinted exactly as it was.
