# Tray Dock (v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1 cradle deck with a CHRGtime-style flat tray (four bays, cable cutouts, removable dividers), a rounded-corner base holding the charger underneath, and a lift-off lid.

**Architecture:** Same build123d algebra-API project. `tray.py` and `lid.py` are new part modules; `base.py` is reworked for the tray rebate, rounded corners and the tie-down grid; `cradles.py` and `deck.py` are deleted. Tests measure solids. Exports STL + STEP via the existing `scripts/export_all.py` registry.

**Tech Stack:** Python 3.12 via uv, build123d 0.12, pytest. Snapmaker Orca for slicing (see docs/printing.md).

**Spec:** `docs/superpowers/specs/2026-09-20-tray-dock-design.md`

## Global Constraints

- Units mm, Z up, print-bed face at Z=0 for every part.
- WALL 2.4, FLOOR 1.6, TRAY_PLATE 3.0, BAY_DEPTH 28.0, CORNER_R 8.0 (base/lid outer vertical edges).
- CLR_FIT 0.15, CLR_RAIL 0.20, CLR_BAY 3.0 (new), CLR_DEVICE removed.
- BED_X = BED_Y = 250.
- Chamfers not fillets on downward-facing edges; fillets only on vertical edges. No overhang past 45°; bridges ≤ 20 mm allowed.
- Tests measure the built solid; every exported part is one valid solid on the bed (tests/test_parts.py stays).
- `out/` never committed. Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Coordinates: the tray's plate spans X = 0..TRAY_X, centred on Y = 0; the base wraps it with WALL + CLR_FIT per side; `base.tray_seat()` gives the tray's seating Location; the lid is centred on the base's outer footprint.

  - `tray.ROAM_BAY = (x0, y0, w, l)` and `tray.RIGHT_BAYS = {"ion": (...), "trackr": (...), "spare": (...)}` bay interiors as (min X, min Y, X size, Y size) in tray coordinates.
  - `tray.TRAY_X, tray.TRAY_Y` outer plate size; `tray.TRAY_H = TRAY_PLATE + BAY_DEPTH`; `tray.OUTER_R = CORNER_R - WALL - CLR_FIT` corner radius of the tray outline.

  - `build_tray() -> Part`.

Layout (tray coordinates, X = 0..TRAY_X, Y centred on 0):
- Left bay interior: X size = ROAM.width + 2·CLR_BAY (59), Y size = ROAM.length + 2·CLR_BAY + CUTOUT[0] (= 96 + 6 + 22 = 124). Cutout at the −Y end, centred in X.
- Right column interior X size = max over devices of (length + 2·CLR_BAY) + CUTOUT[0] (Ion: 102.5 + 6 + 22 = 130.5). Three bays stacked in Y: heights ION.width + 2·CLR_BAY (40.7), TRACKR.width + 2·CLR_BAY (43.1), spare = 40.0; separated by the two removable dividers (divider THICK = 2.0 counts in the stack). Cutouts at the +X end of each bay, centred in the bay's Y.
- Right column total Y = 40.7 + 2 + 43.1 + 2 + 40 = 127.8; the left bay is stretched to the same Y (its cutout stays at the −Y end).
- Fixed walls: four outer + one partition between the left bay and the right column. TRAY_X = 3·WALL + 59 + 130.5 = 196.7; TRAY_Y = 2·WALL + 127.8 = 132.6.
- Rail slots for the two dividers: cut with `divider.rail_cutter(BAY_DEPTH)` wholly inside the partition wall (its +X face) and the +X outer wall (its −X face), at the two `RAIL_YS`; to keep ≥ WALL behind the slot, the partition wall is `WALL + RAIL_D + CLR_RAIL` thick and the +X outer wall likewise (adjust TRAY_X accordingly and expose the real number).
- Outer vertical corners of the tray filleted `OUTER_R`; plate bottom outer edge chamfered 1.0 (downward edge); bay inner corners square.
- Cable cutouts: `Box(CUTOUT[0], CUTOUT[1], THRU)` through the plate only (they must not cut walls), positioned 2 mm in from the bay's end wall.

```python
from build123d import Axis
from dock import tray, params, divider
from dock import measurements as m


def test_tray_fits_bed():
    s = tray.build_tray().bounding_box().size
    assert s.X <= params.BED_X and s.Y <= params.BED_Y


def test_tray_is_one_valid_solid_on_bed():
    p = tray.build_tray()
    assert p.is_valid and len(p.solids()) == 1
    assert abs(p.bounding_box().min.Z) < 1e-6
    assert abs(p.bounding_box().size.Z - tray.TRAY_H) < 1e-6


def test_four_cable_cutouts_through_the_plate():
    p = tray.build_tray()
    bottom = p.faces().sort_by(Axis.Z)[0]
    wires = bottom.inner_wires()
    assert len(wires) == 4
    for w in wires:
        s = w.bounding_box().size
        assert {round(s.X, 3), round(s.Y, 3)} == {tray.CUTOUT[0], tray.CUTOUT[1]}


def test_each_device_fits_its_bay_with_clearance():
    for dev, (x0, y0, w, l) in ((m.ROAM, tray.ROAM_BAY),):
        assert w >= dev.width + 2 * params.CLR_BAY - 1e-6
        assert l >= dev.length + 2 * params.CLR_BAY + tray.CUTOUT[0] - 1e-6
    for name, dev in (("ion", m.ION), ("trackr", m.TRACKR)):
        x0, y0, w, l = tray.RIGHT_BAYS[name]
        assert w >= dev.length + 2 * params.CLR_BAY + tray.CUTOUT[0] - 1e-6
        assert l >= dev.width + 2 * params.CLR_BAY - 1e-6


def test_bays_are_open_voids_of_full_depth():
    """A box the size of each bay interior, sitting on the plate, does not intersect the tray."""
    from build123d import Box, Pos, Align
    p = tray.build_tray()
    bays = [tray.ROAM_BAY, *tray.RIGHT_BAYS.values()]
    for (x0, y0, w, l) in bays:
        probe = Pos(x0 + w / 2, y0 + l / 2, params.TRAY_PLATE) * Box(w - 0.01, l - 0.01, params.BAY_DEPTH - 0.01, align=(Align.CENTER, Align.CENTER, Align.MIN))
        assert (probe & p).volume < 1e-3


def test_divider_drops_into_both_rail_positions():
    from build123d import Pos
    p = tray.build_tray()
    d = divider.build_divider(height=params.BAY_DEPTH, width=tray.RIGHT_BAY_W - params.CLR_RAIL)
    for y in tray.RAIL_YS:
        placed = Pos(tray.RIGHT_BAYS["ion"][0] + tray.RIGHT_BAY_W / 2, y, params.TRAY_PLATE) * d
        assert (placed & p).volume < 1e-3


def test_walls_keep_full_thickness_behind_rail_slots():
    """Probe the material behind each rail slot: at least WALL remains."""
    from build123d import Box, Pos, Align
    p = tray.build_tray()
    x_part = tray.RIGHT_BAYS["ion"][0]          # partition's +X face
    for y in tray.RAIL_YS:
        probe = Pos(x_part - divider.RAIL_D - params.CLR_RAIL - params.WALL / 2, y, params.TRAY_PLATE + 1) * Box(params.WALL - 0.02, 2, params.BAY_DEPTH - 2, align=(Align.CENTER, Align.CENTER, Align.MIN))
        assert abs((probe & p).volume - probe.volume) < 1e-3


def test_outer_corners_are_rounded():
    from build123d import GeomType
    p = tray.build_tray()
    cyl = [f for f in p.faces() if f.geom_type == GeomType.CYLINDER and abs(f.radius - tray.OUTER_R) < 1e-6]
    assert len(cyl) >= 4


def test_no_overhang_past_45_degrees():
    import math
    p = tray.build_tray()
    for f in p.faces():
        n = f.normal_at()
        if n.Z < -1e-6 and f.center().Z > 1e-6:
            angle = math.degrees(math.acos(-n.Z))   # 0 = flat ceiling
            assert angle >= 45 - 1e-6 or f.bounding_box().size.length <= 20, f.center()
```
